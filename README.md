### Featured projects

**[ECG lead reduction](https://github.com/Im-yusuf/DISS_final)** · my BSc dissertation, awarded a strong First  
How few ECG leads can a deep-learning classifier use before its diagnoses stop being reliable? I trained two PyTorch models on 35,053 hospital ECGs across six lead sets. With just four leads they keep 99.7% and 99.9% of their 12-lead macro AUROC and beat the standard 6-lead set. Integrated Gradients, written from scratch, shows which leads they rely on.

**[roommix](https://github.com/Im-yusuf/roommix)** · real-time audio mixing for face-to-face translation  
Phones in the same room each stream live audio, and roommix merges them into one clean 16 kHz stream for speech recognition, handling clock drift and voices picked up twice. It has a dependency-free TypeScript core, a Node.js WebSocket server and a browser simulator. [Live demo](https://f2f-audio-mixer.web.app)
